# ipam

只依赖 Python 标准库的地址池分配内核：地址池由起始地址与前缀长度确定，池内的
空闲空间按 (起始地址, 前缀长度) 的块登记，分配走首次适配，释放把块放回空闲表并
按伙伴关系与相邻的空闲块合并，另外可以把一段地址预留成不可分配，并统计已分配、
预留、空闲的地址数与利用率。

地址一律用整数表示，内核不做点分十进制解析、不联网、不读写文件、不取真实时钟、
不使用随机数，同一个调用序列永远得到同样的结果。

- `ipam/core.py` — 地址池内核：前缀切分、首次适配、释放合并、预留、统计。
- `tests/test_core.py` — 验收用例。

## 运行测试

在项目根目录执行：

```
python3 -m unittest discover -s tests -v
```

Windows 上如果没有 `python3`，可用：

```
python -m unittest discover -s tests -v
```
